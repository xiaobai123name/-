## 每篇文档的结构

每篇教学文档都采用统一的 Q&A 格式：

1. **提出问题** —— 先知道「要回答什么」
2. **给出答案** —— 聚焦逻辑和设计思路
3. **小结** —— 列出学完后应该能回答的问题清单
